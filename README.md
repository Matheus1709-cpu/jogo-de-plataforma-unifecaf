# 🎮 Jogo de Plataforma 2D - UniFECAF

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento de Jogos 2D na **UniFECAF**.

---

## 📝 Sobre o Jogo
Jogo de plataforma 2D feito na engine **Unity**, contando com mecânicas de movimentação do personagem, colisões, sistema de fases, efeitos sonoros e visuais.

---

## 🕹️ Controles
* **A / D** ou **Setas (Esquerda / Direita):** Mover o personagem
* **Espaço:** Pular
* **Esc:** Pause / Menu

---

## 🚀 Como Jogar / Executar
1. Baixe o arquivo **`Build.zip`** que está anexado neste repositório.
2. Extraia o conteúdo do `.zip` para uma pasta no seu computador.
3. Abra a pasta extraída e dê um duplo clique no arquivo **`Jogo de plataforma 2D Unifecaf.exe`**.

---

## 🛠️ Tecnologias Utilizadas
* **Engine:** Unity 2D
* **Linguagem:** C#
* **Plataforma:** Windows (PC)
